📊 Student Performance SQL Analysis
📌 Project Overview

This project analyzes student performance data from two schools to identify key factors that influence academic outcomes. The analysis focuses on behavioral, social, and demographic variables affecting final grades (G3).

🎯 Objective
Analyze factors impacting student performance
Compare results between two schools
Generate insights using SQL
🗂️ Dataset

The dataset contains student information from two schools:

students_gp (Gabriel Pereira)
students_ms (Mousinho da Silveira)

Key columns:

Academic: G1, G2, G3
Behavior: studytime, absences, dalc, walc
Social: famsup, activities
Demographics: age, address
⚙️ Tools Used
SQL (MySQL / PostgreSQL)
Data Analysis Techniques
🔍 Key Analysis Performed
Compared academic performance between schools
Analyzed impact of study time on grades
Evaluated effect of alcohol consumption
Studied relationship between absences and grades
Compared performance based on family support
Analyzed impact of extracurricular activities
Compared urban vs rural student performance
📈 Key Insights
Higher study time is associated with better academic performance
Increased absences correlate with lower grades
Higher alcohol consumption is linked to lower grades
Family support showed no significant impact on performance
GP students performed better on average despite higher absences
Minimal difference observed between students with and without activities
🧠 Conclusion

Student performance is influenced more by behavioral factors such as study time and attendance, while some social factors like family support and activities show limited impact.
